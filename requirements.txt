# Synaptech ERP — Workspace Requirements

## 1. System & Environment Requirements
- Node.js >= 18.0.0 (npm >= 9.0.0)
- .NET 10 SDK (`net10.0`)
- PostgreSQL Database Server (>= 14.0)

- Angular CLI 22.1.6
- Angular Core 22.1.0
- TypeScript 6.0.2

### Main Dependencies:
- `@angular/core`: ^22.1.0
- `@angular/common`: ^22.1.0
- `@angular/forms`: ^22.1.0
- `@angular/router`: ^22.1.0
- `@microsoft/signalr`: ^10.0.11
- `rxjs`: ~7.8.0
